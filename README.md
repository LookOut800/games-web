# LookOut800 Games (test builds)

Static showcase of Godot web test builds, served at https://charlesmtalbot.com/games-web/ (GitHub Pages; `.nojekyll`
keeps Pages from touching the export files). Not a project: a build artifact. Source stays in each game's repo.

| Path | What it is |
|---|---|
| `index.html` | The page, cards pre-rendered (no fetch) |
| `games.json` | Same data as the cards: id, title, status, version (`<version>+<commit>[-dirty]`), generated date |
| `<game>/` | That game's web export (`index.html`, `.wasm`, `.pck`, ...) |

Games (2026-10-15): wingmates (playable), hardpoint, wreck-runner, lantern-hold, the-dig, marigold-maintenance-club,
cyber-party-battler, diorama-3d (prototypes).

## Updating
The page and `games.json` are generated by a script that lives outside this repo (on the owner's machine); note its
path here when it's next run. Rules worth keeping:
- Build from clean commits: a `-dirty` version means the export came from uncommitted changes and can't be
  reproduced (5 of 8 are dirty today).
- Every snapshot adds ~300 MB of binaries to git history. Before it gets heavy: Git LFS for `*.wasm` / `*.pck`, or
  deploy the folder directly (Cloudflare Pages direct upload) instead of committing it.

Planned successor: the Games index site in talbot-sites (`talbot-sites/docs/PROJECTS.md`).
